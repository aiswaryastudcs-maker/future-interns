# FUTURE_PE_01

## Task 1 – AI Website Copy Generator for Local Businesses

### Business
Glow & Grace Salon

### About the Project
This project is about creating website content for a local salon using AI.

The content includes a homepage, service descriptions and call-to-action sections. I used structured prompts to create simple, clear and customer-friendly website copy.

### Content Included

- Homepage headline and introduction
- Value proposition
- Services and descriptions
- Call-to-action sections
- Tone adaptation

### Tools Used

- ChatGPT
- GitHub
- Markdown

### Files

- `prompts.md` – Prompts used to generate the content
- `website-copy.md` – Final website copy

### Objective

To create simple, persuasive and website-ready content for a local business using AI and prompt engineering.
